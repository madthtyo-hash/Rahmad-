☁️ Database Online (Supabase) — Opsional

Kalau diaktifkan, RSVP & daftar tamu dari HP tamu mana pun langsung tersimpan ke satu database online — jadi Anda bisa memantau konfirmasi tanpa memegang HP tamu. Petunjuk lengkap ada di supabase/README.md.

“Kirim” menyalin undangan + RSVP dari perangkat ini ke Supabase. “Ambil” menarik RSVP/daftar tamu terbaru dari Supabase ke perangkat ini. Uji Lengkap memeriksa 5 hal sekaligus: konfigurasi, skema database, izin kirim RSVP, privasi nomor HP tamu, dan apakah undangan aman dari perubahan — aman diulang, tidak mengubah data Anda.

File backup berformat .json. Di browser yang mendukung, Anda bisa langsung memilih folder HP/laptop tujuan; jika tidak, file otomatis masuk ke folder Download.

Data tidak dikirim ke pihak ketiga — hanya tersimpan di perangkat Anda & Backend Studio milik sendiri.

📲 Koneksi WhatsAppMemeriksa…

Kirim undangan lewat WhatsApp dengan dua cara: Link WhatsApp (gratis) — membuka chat dengan pesan & link siap kirim, tanpa token; atau Gateway otomatis (Fonnte / Wablas / Whacenter / Custom) — server yang mengirim, termasuk notifikasi RSVP baru ke nomor Anda.

🔗 Link WhatsApp (gratis) Selalu tersedia tanpa pengaturan apa pun. Klik “Kirim Link Undangan”, chat WhatsApp terbuka dengan pesan yang sudah terisi.
🚀 Gateway otomatis Belum dikonfigurasi.
Kode yang bisa dipakai: {tamu}, {acara}, {tanggal}, {lokasi}, {link}.
—
⚙️ Pengaturan Gateway (opsional)
  1. Daftar di gateway pilihan Anda (contoh: Fonnte, Wablas, atau Whacenter) lalu salin token-nya.
  2. Di server, salin wa-config.example.json menjadi wa-config.json, isi token, provider, lalu ubah "enabled": true.
  3. Jalankan ulang server, lalu tekan Muat Status di bawah. Token tidak pernah dikirim ke browser.
